# Click

Стеклянная панель для Windows с виджетами и живыми ассистентами — Патриком и Терезой.

**[Сайт Click](https://click-desktop.talldot1.chatgpt.site)** · Windows x64 · текущая версия **1.0.5**

## Скачать

Готовый установщик `Click-Setup-1.0.5.exe` публикуется в разделе **Releases**. Приложение также можно скачать на сайте Click.

Начиная с версии 1.0.5 новые опубликованные версии доступны прямо в приложении: **Настройки → Обновления**. Настройки и личные данные сохраняются при установке поверх предыдущей версии.

## Возможности

- Закреплённые приложения, открытые окна и виджеты на одной панели.
- Музыка, задачи, погода, часы, помодоро и показатели системы.
- Прозрачность, масштаб, расположение блоков и автоскрытие.
- Ассистенты Патрик и Тереза: прогулка, реакции, напоминания и команды. Ассистента можно перетаскивать и подбрасывать мышью.
- Проверка обновлений, загрузка с прогрессом и проверка целостности установщика.

Разговоры с ИИ и облачное распознавание голоса настраиваются отдельно с собственными API-ключами пользователя. Личные ключи не входят в исходники или установщик.

## Запуск из исходников

Нужны Windows x64, Node.js 24 и npm.

```powershell
npm ci
npm start
```

Внутреннее имя npm-пакета — `glassdock`; название приложения — **Click**.

## Сборка установщика

```powershell
node tools/build.js
```

Результат: папка `dist/Click-win32-x64`, установщик `dist/Click-Setup-<версия>.exe` и файлы обновления `dist/update-release`.

Сборка использует Electron Packager и компилятор C# из .NET Framework в Windows. Установка не требует прав администратора. Папка программы по умолчанию — `%LOCALAPPDATA%\Programs\Click`.

## Проверки

```powershell
node tools/test-dock.js
node tools/test-flight.js
node tools/test-hold.js
node tools/test-updates.js
```

Эти проверки не запускают установщик и не изменяют рабочий стол.

## Данные пользователя

Настройки, задачи и ключи хранятся отдельно от программы: `%APPDATA%\GlassDock\data`. Каталоги с моделями распознавания речи, локальные настройки, ключи, кэш и `node_modules` не публикуются в репозитории.

## Новые версии

Перед сборкой обновите `version` в `package.json` и `package-lock.json`, а также `release-notes.json`. Подробности публикации — в [tools/UPDATES.md](tools/UPDATES.md).
