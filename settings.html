Приложения

Закреплённые
Перетаскивайте, чтобы поменять порядок. Без капсулы — стоят слева у «Пуска». Клик по открытому приложению переключает на его окно, средняя кнопка мыши — новое окно

Отдельная капсула с иконками всех открытых окон, которые не закреплены. Клик — переключиться, по активному — свернуть

Соцсети

Аккаунты
Число подписчиков обновляется каждые 30 минут и показывается на панели. Перетаскивайте строки, чтобы поменять порядок
Добавить аккаунт
Ключи (необязательно)
YouTube API key
Без ключа YouTube отдаёт число округлённым (например, 30,7 млн). С ключом — точное. Ключ бесплатный: Google Cloud Console → YouTube Data API v3 → Credentials
Токен ВКонтакте
Нужен только для ВКонтакте: без него VK число не показывает. Подойдёт сервисный ключ своего приложения (vk.com/apps?act=manage → Настройки → Сервисный ключ доступа)

Instagram и X (Twitter) без входа в аккаунт число подписчиков не показывают, поэтому их здесь нет. Twitch считается через открытый сервис decapi.me.

Система

Запускать вместе с Windows
Док появится сразу после входа в систему
Окна не заходят на панель
Развёрнутые окна заканчиваются над доком, как над панелью задач Windows. Выключите, чтобы окна занимали весь экран, а док лежал поверх
Скрывать панель задач Windows
Пока Click запущен, стандартная панель не появляется. После выхода она вернётся, даже если док упадёт. Трей, звук и сеть — Win+A, уведомления — Win+N
