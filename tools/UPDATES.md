# Публикация новой версии Click

1. Увеличить версию в package.json и package-lock.json, обновить release-notes.json и CHANGELOG.
2. Запустить проверки и `node tools/build.js`. Он собирает установщик и каталог `dist/update-release` для перехода со старого канала.
3. Опубликовать исходники в `mentalmollie/click-desktop`. Создать обычный GitHub Release с тегом `v<версия>` на соответствующем коммите.
4. Прикрепить `Click-Setup-<версия>.exe` и `SHA256SUMS.txt`. Дождаться завершения загрузки и появления у установщика `digest: sha256:<сумма>` в GitHub API. Опубликовать релиз.
5. Click 1.0.6 и новее проверяет последний стабильный релиз GitHub, загружает установщик с прогрессом и проверяет SHA256. Черновики и предварительные версии не предлагаются. Раздел «Что нового» показывает 10 стабильных релизов и сохраняет описание установленной версии без сети.
6. Проверить реальную загрузку без входа: `node tools/verify-published-update.js`. Установщик не запускается.

Для пользователей 1.0.5 сохранить старый канал: из проекта `click-website` запустить `node scripts/sync-release.cjs "D:\claude code\glassdock\dist\update-release"` и `node scripts/verify-site.cjs`, затем опубликовать через Sites с прежним project_id и аудиторией. Не удалять `/updates/latest.json`: этот канал переводит старые установки на новую версию.

Один установщик хранится на сайте частями до 20 МиБ из-за ограничения на размер статического файла. И сайт, и приложение собирают исходный EXE в правильном порядке, проверяя SHA-256 частей. Приложение также проверяет SHA-256 всего файла перед скачиванием до конца и перед запуском. Настройки и ключи не входят в публикацию.

Яндекс Погода подключается собственным API-ключом пользователя в настройках. Ключ хранится зашифрованным только на компьютере в `weather-yandex.key`. Панель, прогноз и ассистент используют официальный API v3 и общий кэш. До ввода ключа приложение предлагает подключение.

Проверки: `test-dock.js`, `test-flight.js`, `test-hold.js`, `test-updates.js`, `test-github-updates.js`, `test-weather.js` в каталоге `tools`.
