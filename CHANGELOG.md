# Изменения

## 1.0.6

Обновления напрямую из GitHub Releases.
Новая вкладка «Что нового» и ссылка на GitHub.
Удалены интеграция с Island и Claude из списка нейросетей.
Подключение Яндекс Погоды по API-ключу в настройках. Панель, прогноз и ассистент используют общие погодные данные.


## 1.0.5

- Добавлен раздел «Обновления» в настройках и пункт обновлений в меню приложения.
- Новые версии скачиваются прямо из Click с отображением прогресса и возможностью отмены.
- Перед установкой проверяется целостность скачанного файла.
- Установщик открывается с текущей папкой приложения; настройки и данные сохраняются.
- Включены предыдущие исправления удержания ассистента, подбрасывания и движения при автоскрытии панели.
